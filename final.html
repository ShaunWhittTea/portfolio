Final Project

Collaborative Full-Stack Web Project

This final project is a collaborative web application built to demonstrate team-based development, iterative delivery, and deployment of a working backend service. What makes it interesting is that it reflects real project workflow through multiple phases, shared responsibilities, and hosted execution. One important architecture decision was separating the deployed backend service from the portfolio itself, allowing the application logic and API behavior to be tested independently.
