## Architecture / Design Notes
The portfolio is built as a multi-page static website with a consistent design system across all pages. Each project has its own dedicated page, allowing a clear navigation path from the homepage to a live deployed application. The structure is designed to prioritize user experience, making it easy to quickly access and evaluate projects.
